# Grana Certa 💰

Aplicativo simples de controle financeiro pessoal.

## Funcionalidades
- Cadastro de receitas e despesas
- Saldo automático
- Categorias financeiras
- Histórico de movimentações
- Exclusão de lançamentos
- Dados salvos no navegador (localStorage)
- Tema claro e escuro

## Como usar
Abra o arquivo `index.html` no navegador ou publique o projeto usando GitHub Pages.
